# 3.3. Контракт мобильного API

Основной файл [openapi.yaml](openapi.yaml) — OpenAPI 3.0.3 по итоговому списку сдачи. Дополнительный [openapi-3.2.yaml](openapi-3.2.yaml) описывает **тот же API** в OpenAPI 3.2.0, поскольку текст подзадачи одновременно требует 3.2. Отличается только поле `openapi`; использованные элементы совместимы, два разных API не вводятся. Версии проверяются отдельно.

`GET /api/v1/appointments?status=upcoming&limit=20&offset=0` возвращает предстоящие подтверждённые записи текущего пациента. PatientId берётся из серверного сопоставления JWT subject; параметр чужого пациента отсутствует. Upcoming означает startsAt позже serverTime выборки и status=confirmed; hold, cancelled и незавершённые Saga не включаются, их состояние читается отдельно по operationId. Все время в RFC3339 UTC, часовой пояс клиники указан отдельно для отображения.

Offset/limit выбраны согласно заданию и подходят для короткого списка персональных записей: limit по умолчанию 20, максимум 100, offset ≥0. Стабильная сортировка `(startsAt, id)`; при изменении списка между запросами возможны сдвиги/пропуски — клиент при обновлении начинает с offset=0 и дедуплицирует id. Offset не обещает snapshot consistency и не подходит для массовой выгрузки; при росте потребности будет cursor/snapshot endpoint отдельной версии. `hasMore` определяется чтением limit+1, total не вычисляется тяжёлым COUNT.

Версия бизнес-контракта в URL `/api/v1` независима от версии формата OpenAPI и `info.version`. Совместимые добавления необязательных полей остаются в v1; изменение обязательности/семантики — новая v2 с периодом миграции клиентов и телеметрией использования. Хост `.example` — зарезервированный синтетический адрес, не реальный endpoint.

200, 401 и 500 снабжены примерами; дополнительно 400, 403, 429 и 503 описывают валидацию, полномочия и защиту. Для 401 используется WWW-Authenticate, для 429/503 — Retry-After. Примеры не содержат реальных пациентов/секретов; строки токенов в контракт не включаются. Авторизация и безопасность подробнее в [Task4.3](../Task4.3/README.md).
